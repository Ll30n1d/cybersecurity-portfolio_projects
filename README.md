## 📁 Структура Репозитория

### 📄 [01-networking-basics](./01-networking-basics)
Базовые концепции компьютерных сетей, адресация IPv4/Subnetting, конфигурирование сетевых интерфейсов, DHCP Relay и взаимодействие по протоколу ARP.

### 📄 [02-networking-protocols](./02-networking-protocols)
Анализ работы и настройка сетевых протоколов: DNS, NTP, ICMP, SMB и HTTP/HTTPS.

### 📄 [03-switching-routing](./03-switching-routing)
Проектирование и защита сетевых топологий в GNS3:
- Настройка VLAN, Trunk и EtherChannel
- Динамическая маршрутизация OSPF и отказоустойчивость HSRP
- Защита канального уровня (Switchport security, предотвращение VLAN Hopping через `switchport nonegotiate`)

### 📄 [04-wireshark-scapy](./04-wireshark-scapy)
- **Network Forensics:** Анализ PCAP/PCAPNG дампов трафика в Wireshark, выявление подмены LSA в OSPF, анализ SMB-сессий и обнаружение Reverse Shell.
- **Scapy:** Кастомные Python-скрипты для генерации, модификации и инъекции TCP/IP пакетов.

### 📄 [05-linux-security](./05-linux-security)
Администрирование Linux (CachyOS/Ubuntu), работа с CLI, сканирование и разведка сети с помощью Nmap.
