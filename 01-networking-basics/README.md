# 🌐 01. Networking Basics & IP Fundamentals

В данном разделе представлены практические лабораторные работы и проекты по базовым концепциям построения компьютерных сетей, адресации IPv4, работе с фундаментальными протоколами L2/L3 и первичной настройке сетевого оборудования Cisco[cite: 1].

---

## 🎯 Цели и Задачи
- Освоение модели OSI и стека протоколов TCP/IP[cite: 1].
- Расчет и планирование IPv4-адресации, масок подсетей (Subnetting) и CIDR-нотации[cite: 1].
- Практическая сборка сетевых топологий в среде моделирования **GNS3**[cite: 1].
- Базовая конфигурация маршрутизаторов и коммутаторов Cisco через IOS CLI[cite: 1].
- Настройка и диагностика трансляции сетевых адресов и широковещания (ARP, DHCP Relay)[cite: 1].

---

## 🛠️ Выполненные Работы и Конфигурации

### 1. IPv4 Subnetting & IP Addressing
- Разработка схемы адресации для изоляции узлов внутри сегментированной сети[cite: 1].
- Расчет диапазона хостов, адресов сетей и широковещательных адресов (Broadcast)[cite: 1].

### 2. Cisco IOS CLI & Interface Setup
- Базовая настройка сетевых устройств: назначение имен (hostname), паролей доступа, баннеров и IP-адресов на интерфейсах[cite: 1].
- Настройка и проверка интерфейсов FastEthernet / GigabitEthernet (`show ip interface brief`, `ping`, `traceroute`)[cite: 1].

### 3. DHCP Relay (Helper Address)
- Построение схемы перенаправления DHCP-запросов между различными L3-сегментами[cite: 1].
- Конфигурация команды `ip helper-address` на маршрутизаторах Cisco для трансляции DHCPDISCOVER через агента ретрансляции[cite: 1].

### 4. ARP & Network Troubleshooting
- Исследование работы протокола ARP (Address Resolution Protocol), анализ таблицы ARP (`show ip arp`)[cite: 1].
- Симуляция и разрешение конфликтов IP-адресов, диагностика недостижимости узлов на канальном и сетевом уровнях[cite: 1].
