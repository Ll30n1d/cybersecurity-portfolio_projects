# 🔀 03. Switching, Routing & Infrastructure Security

В данном разделе собраны практические работы по проектированию, конфигурированию и защите корпоративной сетевой инфраструктуры на оборудовании Cisco в среде эмуляции GNS3[cite: 1]. Проекты охватывают технологии L2-коммутации, динамическую маршрутизацию L3, механизмы отказоустойчивости и базовое укрепление (hardening) сетевых устройств[cite: 1].

---

## 🎯 Цели и Задачи
- Изоляция трафика и сегментация сети с использованием **VLAN (802.1Q)** и транковых магистралей[cite: 1].
- Повышение пропускной способности и резервирование каналов с помощью **EtherChannel (LACP/PAGP)**[cite: 1].
- Развертывание протокола динамической маршрутизации **OSPF (Open Shortest Path First)**[cite: 1].
- Обеспечение отказоустойчивости первого хопа (FHRP) через протокол **HSRP (Hot Standby Router Protocol)**[cite: 1].
- Применение мер безопасности на уровнях L2/L3 для защиты от сетевых атак (Switchport Security, предотвращение VLAN Hopping)[cite: 1].

---

## 🛠️ Выполненные Работы и Конфигурации

### 1. VLANs, Trunking & EtherChannel
- Настройка логической сегментации пользовательских сетей (VLAN 10, VLAN 20 и др.)[cite: 1].
- Конфигурирование магистральных портов 802.1Q (Trunk) между коммутаторами[cite: 1].
- Объединение физических интерфейсов в логические агрегированные каналы EtherChannel для балансировки трафика и отказоустойчивости[cite: 1].

### 2. OSPF Dynamic Routing
- Настройка протокола OSPF в однообластной архитектуре (Single-Area OSPF)[cite: 1].
- Объявление подсетей, расчет метрик, выбор DR/BDR и проверка таблицы маршрутизации (`show ip route`, `show ip ospf neighbor`)[cite: 1].

### 3. First Hop Redundancy (HSRP)
- Создание виртуального шлюза по умолчанию для клиентов сети с использованием HSRP[cite: 1].
- Настройка приоритетов роутеров и проверки доступности интерфейсов для мгновенного переключения трафика при отказе основного маршрутизатора[cite: 1].

### 4. L2 Security & Hardening (Switchport Security)
- Защита каналов от атак класса **VLAN Hopping**: явное отключение согласования DTP с помощью команды `switchport nonegotiate` и вывод неиспользуемых портов в изоляцию[cite: 1].
- Настройка `switchport port-security` для ограничений по MAC-адресам на портах доступа (Access ports)[cite: 1].
