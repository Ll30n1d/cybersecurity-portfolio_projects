# 🔍 04. Traffic Analysis, Network Forensics & Scapy

В данном разделе собраны практические работы по глубокому анализу сетевого трафика (Deep Packet Inspection), форензике PCAP/PCAPNG-дампов, выправлению аномалий в сетях и автоматизации работы с сетевыми пакетами с помощью библиотеки **Scapy (Python 3)**[cite: 1].

---

## 🎯 Цели и Задачи
- Анализ сетевого трафика в **Wireshark** для выявления аномалий, вредоносной активности и ошибок в конфигурации сетей[cite: 1].
- Проведение сетевой форензики: извлечение полезной нагрузки (Payload), реконструкция файлов и сессий[cite: 1].
- Исследование механизмов атак на локальные сети (ARP Spoofing / MitM, подмена LSA в OSPF)[cite: 1].
- Разработка кастомных Python-скриптов на базе библиотеки **Scapy** для создания, сборки, модификации и отправки пакетов L2–L4 уровней[cite: 1].

---

## 🛠️ Выполненные Работы и Скрипты

### 1. Network Forensics & Threat Hunting (Wireshark)
- **SMB & File Extraction:** Исследование сессий протокола SMB, извлечение передаваемых файлов из PCAP-дампов трафика[cite: 1].
- **Reverse Shell Detection:** Анализ сетевых дампов на предмет нестандартных TCP-соединений, выявление следов выполнения команд через Reverse Shell[cite: 1].
- **Protocol Anomaly Analysis:** Выявление нетипичного ICMP-трафика, анализ поведения ARP-запросов и выявление попыток ARP-Spoofing (Man-in-the-Middle)[cite: 1].

### 2. Python & Scapy Packet Manipulation
- **Custom Packet Crafting:** Разработка скриптов для ручной сборки кастомных TCP/IP пакетов с произвольными флагами и заголовками[cite: 1].
- **Network Scanning & Sniffing:** Написание легких сканеров портов и перехватчиков пакетов (Sniffers) с фильтрацией BPF (Berkeley Packet Filter)[cite: 1].
- **Protocol Injection & Testing:** Автоматизация инъекций пакетов для проверки устойчивости сетевого оборудования и корректности обработки аномального трафика[cite: 1].

---

## 📁 Структура Файлов в Папке
* `scripts/` — кастомные скрипты на Python (Scapy) для генерации и анализа пакетов[cite: 1].
* `pcaps/` — дамп-файлы сетевого трафика (PCAP/PCAPNG) с примерами аномалий и исследуемых сессий[cite: 1].
* `reports/` — подробные разборы проведенных расследований с дисплейными фильтрами Wireshark (`tcp.flags`, `smb2`, `ip.addr`)[cite: 1].

---

## 💻 Использованные Инструменты
- **Wireshark / TShark** — интерактивный и консольный анализ дампов трафика[cite: 1].
- **Python 3 & Scapy** — программная сборка и инъекция сетевых пакетов[cite: 1].
- **CachyOS / Ubuntu Linux CLI** — среда выполнения скриптов и дампа трафика (`tcpdump`)[cite: 1].
